# ErgoAI

Landing page del prototipo **ErgoAI** — Equipo Kesta, Green House School.
Sistema inteligente de corrección postural preventiva basado en visión por computadora, desarrollado para el reto **Health Makers** de ExpoSTEAM 2026.

Página estática de una sola pieza (HTML + CSS + SVG + JS, sin dependencias externas): tipografías propias embebidas, escena animada del dispositivo "Ergo", y un QR que enlaza a esta misma página.
